집에서 작업했음

github desktop 1. 새 러퍼지토리 생성 -> file -> New repository 2. New repository 옵션에 내용 입력 name Description(생략 가능) ,Local path (저장경로) 지정 후 하단 create repository 버튼 눌러 저장소 생상 3. 지정한 경로에 만들어진 폴더 내부에 프로젝트에 필요한 파일 생성(Html, Css 등) 4. 코드 작업 후 기록을 남기려면 github desktop 을 사용하여 커밋 처리 깃허브에 업로드 5. 커밋하고 작업이 다 끝나면 상단 Fetch Origin이나 push로 깃허브에 업로드 6. 깃허브 저장소 새로고침 하여 업로드 되었는지 확인
